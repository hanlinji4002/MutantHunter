# Bob task sessions

Evidence for judging: every Bob task used to build this project.

For each task, add two files:
- `<milestone>-<member>-<topic>.png`: screenshot of the task session consumption summary
- `<milestone>-<member>-<topic>.md`: the exported task history

Example: `M1-hanlin-harness.png`, `M1-hanlin-harness.md`.

How to export in Bob IDE: chat panel → Views and More Actions → History → open the task → click the task header (consumption summary, take the screenshot) → Export task history.

Before committing, check the exported files for credentials.
